# honja-python

<혼자 공부하는 파이썬>으로 파이썬 기초를 익히고, 챕터마다 배운 문법을 **금융 문제로 바꿔 직접 만든 산출물**을 쌓아두는 저장소입니다.

- 기간: 2026.11 – 2026.12
- 환경: Google Colab
- 방식: 챕터를 마칠 때마다 산출물 노트북 1개를 `chXX/` 폴더에 저장

## 챕터 산출물

| 챕터 | 산출물 | 핵심 문법 | 상태 |
|---|---|---|---|
| Ch02 자료형 | 복리 만기액 계산기 | 숫자·문자열, input, f-string | 예정 |
| Ch03 조건문 | 신용점수별 대출금리 판정기 | if · elif · else | 예정 |
| Ch04 반복문 | 종목별 수익률 정리표 | 리스트, 딕셔너리, for | 예정 |
| Ch05 함수 | 대출 원리금균등상환표 | 함수, 매개변수, return | 예정 |
| Ch06 예외 처리 | 상환표 계산기 입력 오류 처리 | try · except | 예정 |
| Ch07 모듈 | 실제 주가로 일간 수익률 구하기 | 표준·외부 모듈, datetime | 예정 |
| Ch08 클래스 | 포트폴리오 클래스 (종합) | 클래스, 메서드 | 예정 |

## 폴더 구조

```
honja-python/
├── ch02/
├── ch03/
├── ...
└── ch08/
```

## 기록 규칙

- 노트북 맨 위에 과제 설명, 맨 아래에 결과 해석 2~3줄을 남긴다.
- 개인정보·API 키는 올리지 않는다.
- 챕터를 마치면 위 표의 상태를 `완료`로 바꾸고 노트북 링크를 단다.
